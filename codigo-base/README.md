# Athen

Projeto educacional desenvolvido com React, TypeScript, Vite e Supabase.

## Comandos

npm install
npm run dev
npm run build
npm run typecheck
npm run test

## Estrutura

- src/: aplicação React
- supabase/: migrations e seed SQL
- tests/: testes automatizados
- .env.local: configuração local, não versionada
